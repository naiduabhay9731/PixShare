



# PixShare



PixShare is a full-stack social media application built to allow users to connect, share, and engage with one another through posts, comments, and likes. It features secure user authentication, friend management, and a modern user interface for an immersive social media experience.

## Project Overview

- **Frontend**: Developed using **ReactJS**, providing a responsive and dynamic interface with features like profile creation, posting content, and interacting with posts (likes and comments). 
- **Backend**: Powered by **Node.js** and **Express.js**, handling server-side logic and API routing. Integrated **MongoDB** for data storage.
- **Authentication**: Implemented secure user authentication using **bcrypt** for password hashing and session management.
- **Key Features**:
  - Profile creation and management
  - Posting, liking, and commenting on posts
  - Adding and managing friends for a connected experience
  - Real-time updates with responsive page reloading
  - Deployed on [Netlify](https://pixshare21.netlify.app) for easy access.

## Installation Instructions

Navigate to the `client` directory:
```bash
npm install
```
Then

```bash
npm start
```
Navigate to the server directory:
```bash
npm install
```
Start the server:

```bash
node app.js
```
